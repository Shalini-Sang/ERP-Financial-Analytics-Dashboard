# ERP Financial Performance & Working Capital Analytics Dashboard

### SQL | Power BI | DAX | Power Query

This is an end-to-end business analytics project based on a large ERP dataset.

The dataset belongs to a fictional B2B company and contains financial transactions, accounts receivable, accounts payable, and employee expense data for 2024–2025.

---

## Project Overview

In this project, I analyzed **380,000+ records** to understand:

- Financial performance (Revenue, Profit, Margin)
- Budget vs Actual variance
- Accounts Receivable and Accounts Payable (Working Capital)
- Employee expenses
- Data quality issues

---

## Tools Used

- SQL
- Power Query
- Power BI
- DAX

---

## Key Findings

- Total Revenue is around **₹15.3 Billion**
- Profit Margin is approximately **33%**
- Actual revenue is **below budget**
- Around **50%** of receivables are still outstanding
- Employee expenses are evenly distributed across Approved, Pending, and Rejected statuses

---

## Dashboard Pages

1. **Executive Overview** – KPIs, trends, region and product performance
2. **Financial Performance** – Budget vs Actual, department and category analysis
3. **Working Capital** – AR/AP outstanding and ageing analysis
4. **Employee Expenses** – Status, department and expense type breakdown

---

## Data Quality Notes

- Cost column had missing values which were handled carefully
- Customer ID did not match well between ledger and receivables, so tables were kept separate
- Measures were filtered properly on Account Type = Revenue
